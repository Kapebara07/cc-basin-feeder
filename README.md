# Basin Feeder (CC: Tweaked + Create)

Кормит 16 бассейнов Create самородками и гравием, раскладывает лишнее по хранилищам
(у каждого предмета своё, при переполнении лишнее удаляется в мусорку), а умелая
черепашка переделывает самородки в слитки.

## Установка и обновление — одна команда

На компьютере и на черепашке одна и та же:

```
wget run https://raw.githubusercontent.com/Kapebara07/cc-basin-feeder/main/install.lua
```

- На **компьютере** ставит `basins.lua` и запускалку `startup.lua`.
- На **умелой черепашке** ставит крафтер самородков как `startup.lua`
  (сундук над черепашкой — вход, сундук под ней — выход).

Настройки (`basins.cfg`) при обновлении сохраняются. Чужой `startup.lua`
сохраняется как `startup.lua.bak`. После установки устройство перезагружается.

## Файлы

| Файл | Что это |
|---|---|
| `basins.lua` | кормушка: меню, экран состояния, мониторы |
| `startup.lua` | запускалка для компьютера, перезапускает кормушку, если та остановилась |
| `turtle.lua` | крафтер самородков для умелой черепашки |
| `install.lua` | установщик |
